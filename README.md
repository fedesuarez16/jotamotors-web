# Jotamotors landing

Sitio independiente del CRM, construido con Next.js y Tailwind CSS.

```bash
cd /Users/federicosuarez/jotamotors/landing
npm install
npm run dev
```

Abrir http://localhost:3001 (la landing está en `/`).

Producción: `npm run build` y `npm start`.

Contenido: `src/app/page.tsx`. Estilos: `src/app/landing.css`.
Logo y fotos del sitio original: `public/landing/`.
